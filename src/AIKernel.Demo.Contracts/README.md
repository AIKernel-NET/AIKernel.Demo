# AIKernel.Demo.Contracts

Shows public Contracts, DTOs, Enums, and execution HashChain DTOs as data-only
boundary objects.

Run:

```powershell
dotnet run --project src/AIKernel.Demo.Contracts/AIKernel.Demo.Contracts.csproj -c Release
```

Expected log shape:

```text
AIKernel.Demo.Contracts
context.id=demo.context
decision.allowed=True
hashchain.algorithm=SHA256
hashchain.structure=sha256:structure
```
